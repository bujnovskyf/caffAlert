Why we use data

We use data to create and manage an account, sync entries between devices, show statistics, keep the service secure, and resolve technical issues. The legal basis is performance of the contract when using the app and our legitimate interest in operating it securely.

Where data is processed

Accounts and entries are processed through Supabase, which provides the database and authentication. This website and the deletion-request form run on Netlify. If Sentry is enabled for a deployment, it is used only for technical error reports; the app does not send default personally identifiable information.

Retention and deletion

We retain the account, profile, and coffee entries for the life of the account. The account can be deleted immediately in the app’s Settings. If you cannot access the app, use the public account deletion page; once the request is verified, we remove the account and related data.
